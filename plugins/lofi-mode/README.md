# lofi-mode

Lo-fi beats while Claude works. When a turn runs longer than a few seconds, a soft, seamless loop starts (Rhodes chords, warm bass, swung drums, vinyl crackle). It stops the moment Claude finishes, and the status line shows what's playing ("♪ beats to refactor to").

The loop is original, synthesized for this mod, so there are no licensing worries.

## Install

```
/plugin marketplace add lakmadev/claude-mods
/plugin install lofi-mode@claude-mods
```

`/lofi` toggles it (`/lofi on`, `/lofi off`); the choice is remembered. Settings (`/config`): `volume` (0.35), `delaySeconds` (4). Audio plays on macOS.
